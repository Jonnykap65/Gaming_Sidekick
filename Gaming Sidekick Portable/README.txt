Gaming Sidekick Standalone

Run the app:
  Double-click "Gaming Sidekick Standalone.exe".

What this is:
  This is a single-file Windows app version of Gaming Sidekick.
  The HTML app and game controller icon are bundled inside the EXE.
  You do not need a separate index.html file.

Runtime data:
  The app creates and uses the "Profile" folder beside the EXE.
  This folder stores the browser profile and local app data, including your saved game library.
  Keep the Profile folder with the EXE if you move the app and want to keep your data.

Portability:
  To move the app to another Windows computer or folder, copy:
    Gaming Sidekick Standalone.exe
    Profile

Reset:
  To reset the app completely, close Gaming Sidekick and delete the Profile folder.
